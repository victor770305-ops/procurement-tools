# 糰糰夥伴 — 門市夥伴電子雞（原型）

完成每天的門市任務，養大屬於自己的夥伴寵物。這是一個不需要安裝的手機網頁，只有 `index.html` 一個檔案，打開就能玩。

## 設計原則

| 原則 | 做法 |
|---|---|
| 只給獎勵，不給懲罰 | 寵物不會死，數值最低到 0 只會變得沒精神。離開超過 20 小時回來會收到「歡迎回來」禮物。 |
| 沒有真實獎勵，靠內在動機 | 進化分支、圖鑑收集、稱號、小屋裝潢、同事打氣、名人堂。 |
| 一人一隻寵物 | 個人寵物；同店夥伴的寵物會一起出現在「門市廣場」。 |
| 任務要能驗證 | 有勾選清單、拍照、計數、測驗四種驗證方式。拍照任務會標示「待店長確認」。 |
| 公平 | 跨店排行比「完成率」，不比數量；每月 2 張休假保護卡，休假不會斷連續紀錄。 |

## 遊戲循環

```
每日：門市任務（3 核心 + 每日一題 + 2~3 加分）→ 經驗／🍙飼料／🪙金幣
      → 照顧寵物（餵食、清潔、玩耍、哄睡）→ 全部完成開每日寶箱
每週：門市團隊挑戰（全店完成數）→ 門市旗幟 + 🪙100
長期：Lv.5 幼年期、Lv.12 成熟期（型態由任務屬性決定）→ Lv.20 畢業
      → 名人堂 → 新的蛋（下一代經驗 +10%，最多 +50%）
```

### 進化路線（14 種型態）

- **蛋 → 糰糰**：完成 3 個任務後孵化。
- **幼年期（Lv.5）**：當下最高的屬性決定型態：盾盾（守護）、齒輪仔（機械）、芽芽（豐收）、心心（親和）、書書（智慧）。
- **成熟期（Lv.12）**：
  - 依最高屬性，分別進化為鐵壁騎士、機械博士、豐收之王、暖心天使、星空賢者；
  - 五種屬性平均發展時，進化為**彩虹糰**；
  - 連續達成 21 天以上時，進化為隱藏型態**流星糰**。

### 任務屬性對應

| 屬性 | 任務類型 |
|---|---|
| 🛡️ 守護 | 開店／閉店 SOP、兌幣機 |
| ⚙️ 機械 | 機台清潔、夾力測試、故障回報 |
| 📦 豐收 | 補貨、陳列、庫存點檢 |
| 💖 親和 | 協助顧客、會員推廣、環境巡視 |
| 📘 智慧 | 每日一題、閱讀公告 |

### 數值（調整位置在 `index.html` 的 `CONFIG`、`TASKS`）

- 升級所需經驗：`40 + 等級 × 20`。
- 每天穩定完成任務的話：約 2 週進入成熟期，約 5 週可以畢業。
- 照顧動作每天最多給 24 點經驗，避免只靠點寵物刷經驗。
- 數值衰減（每小時）：飽足 -5、心情 -4、清潔 -3、精力 -3。睡覺時精力每小時 +25。

## 掛進店務系統

### 1. 直接帶入身分（略過填寫名字與門市）

```
pet/index.html?uid=<員工編號>&name=<姓名>&store=<門市名稱>&shift=early|late|full
```

每個 `uid` 的進度分開存。

### 2. 店務系統完成任務時，同步給寵物

用 iframe 嵌入時：

```js
iframe.contentWindow.postMessage({ type: 'mochi:completeTask', code: 'RESTOCK_HOT' }, '*');
```

在同一個頁面時：

```js
MochiPartner.completeTask('RESTOCK_HOT');
```

### 3. 寵物頁面完成任務時，通知店務系統

寵物頁面會發出這個事件：

```js
window.addEventListener('message', e => {
  if (e.data.type === 'mochi:taskCompleted') { /* e.data.code, e.data.uid, e.data.at */ }
});
```

### 正式上線前要換掉的部分

| 項目 | 目前 | 正式版 |
|---|---|---|
| 存檔 | 手機瀏覽器 localStorage | `Store.load/save` 改呼叫店務系統 API（換手機也不會遺失進度） |
| 任務清單 | `TASKS` + `genTasks()` 依班別產生 | 由店務系統派發 |
| 同事／排行 | `colleagues()` 模擬資料 | 店務系統的同店名單與完成率 |
| 拍照審核 | 照片縮圖存在本機 | 上傳到店務系統，給店長審核 |
| 每日一題 | `QUIZ` 範例題 | 換成公司真實 SOP 題庫 |
| `CONFIG.parentOrigin` | `'*'` | 改成店務系統的網域 |

## 後續可擴充

- **店長審核頁**：查看待確認的照片任務，審核通過後加發獎勵。
- **月度賽季**：每月一組限定擺飾與賽季任務線。
- **季節活動**：配合春節、暑假、週年慶推出限定型態。
- **美術升級**：用 Rive／Spine 製作正式動畫，擺飾換成專屬插畫（目前用 emoji 暫代）。
