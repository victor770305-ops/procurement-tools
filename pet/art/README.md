# 糰糰夥伴 美術資源

## 角色（正式版）

角色原畫來自 `source/sheet1.png` ~ `sheet4.png`（Creature Roster Sheet 1–4），共 20 個家族 × 3 階段 = 60 個型態。

| 檔案 | 用途 |
|---|---|
| `source/sheet*.png` | 原始設定稿（原畫） |
| `creatures/{id}-{stage}.png` | 已去背的角色圖，例如 `g1-3.png` 是神盾要塞龜 |
| `roster.js` | 角色名冊：中文名、原文名、系別、稀有度、概念說明 |
| `gallery.html` | 角色設定集（瀏覽器打開即可） |
| `sheets/*.jpg` | 設定集圖片：每系一張、完全體總覽、遊戲規劃 |
| `tools/extract_sprites.py` | 從設定稿裁切、去背的程式（只需 numpy + Pillow） |
| `tools/contact_sheet.py` | 去背結果檢查總表 |

### 取得與進化

| 項目 | 規則 |
|---|---|
| 第一隻 | 從 5 隻初始角色中選 1 隻。 |
| 之後的蛋 | 畢業後選蛋；連續 14 天 → 稀有蛋；夾娃娃機小機率夾到稀有蛋；每週團隊挑戰 → 蛋券。 |
| 進化 | Lv.5 進成長期。Lv.12 而且自己系別任務佔 30% 以上，才進化成完全體。 |
| 店寵 | 依全店最常做的任務系別，孵出該系的傳說角色。 |

### 換掉或新增角色

1. 新的設定稿要沿用同樣版面：5 列、每列 3 個階段、底下有名牌。
2. 把設定稿放進 `source/`。
3. 執行 `python3 tools/extract_sprites.py`。
4. 在 `roster.js` 補上角色資料。

### 尚缺的美術

- **系別蛋**：設定稿裡沒有，目前沿用舊版的向量蛋。
- **第三階段大型角色的腳**：原稿的名牌壓在角色腳上，去背時只能從名牌上緣切齊。如果有不帶名牌的原圖，可以重新裁切，就不會被切到。

## 牧場環境（草稿：`ranch.js`、`ranch.html`、`ranch-sheets/`）

每家門市是一座牧場，原本的功能都對應到牧場裡的地點：

| 牧場地點 | 遊戲功能 |
|---|---|
| 牧舍 | 個人寵物 |
| 佈告欄 | 每日任務 |
| 中央廣場 | 店寵與全店夥伴 |
| 市集 | 夾娃娃機、商店 |
| 孵蛋屋 | 選蛋、孵化 |
| 名人堂花園 | 畢業寵物 |
| 五系棲息地 | 圖鑑 |

另外，牧場會隨店寵成長，也會依時段與四季變化。

目前的場景美術是向量草稿，裡面的寵物沿用舊版向量角色 `creatures.js`。之後會換成和角色原畫相同風格的牧場美術。
