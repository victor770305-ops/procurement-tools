# 糰糰夥伴 角色美術

20 種原創夥伴寵物 × 3 個進化階段，共 60 個型態，另外 5 顆系別蛋。全部用 SVG 向量繪製，可以直接用在遊戲裡，放大縮小都不會糊。

| 檔案 | 用途 |
|---|---|
| `creatures.js` | 角色美術庫。`Creatures.draw('g1', 3)` 產生「金庫獅」的 SVG |
| `gallery.html` | 角色設定集（瀏覽器打開即可，角色會動） |
| `sheets/*.png` | 設定集圖片：每系一張、完全體總覽、系別蛋、遊戲規劃 |

## 設計原則（參考寶可夢的「設計方法」，角色全部原創）

1. **一眼認得的剪影**：每隻只有一個主記憶點。
2. **進化 = 記憶點長大**：同一個特徵逐階段放大。例如鎖頭吊飾 → 鎖頭尾巴 → 金庫門鬃毛。
3. **三段比例**：
   - 幼年期大頭圓滾；
   - 成長期四肢伸展；
   - 完全體姿態威風，背後有光環。
4. **取材自門市**：夾爪、扭蛋、鐵捲門、兌幣機、禮盒包裝，讓角色有自家品牌的味道，也不會和現有 IP 撞型。

## 放進遊戲的規劃

| 項目 | 規則 |
|---|---|
| 稀有度 | 每系有初始、普通、稀有、傳說各 1 種。傳說 5 種只給門市共養店寵，個人可收集 15 種。 |
| 第一隻 | 新夥伴從 5 顆初始蛋中選 1 顆。 |
| 之後的蛋 | 畢業後可從培育過的系別中選普通蛋。連續 14 天 → 稀有蛋。夾娃娃機有小機率夾到稀有蛋。每週團隊挑戰 → 蛋券。 |
| 進化 | 成長期：Lv.5。完全體：Lv.12，且自己系別的任務屬性要佔 30% 以上。條件不足時，提示要多做哪類任務。 |
| 異色 | 完全體時連續達成 21 天以上，進化成異色版本（`Creatures.draw(id, 3, {shiny:true})`）。 |
| 店寵 | 孵化時，依全店最常做的任務系別，孵出該系的傳說角色。 |
| 圖鑑 | 45 個個人型態 + 15 個店寵型態 + 異色版本。全部收集完約需一年以上。 |
