# 夾娃娃樂園 Claw Club(原型 P0 ~ P2)

網頁版 3D 夾娃娃機經營模擬遊戲。目前完成「寫實機台 + 物理娃娃 + 經營骨架」:營業日、顧客 AI、進貨上架、售價與爪力取捨、每日結算與聲望。桌機與手機皆可操作。

## 執行

```bash
cd claw-machine-sim
npm install
npm run dev      # 開發伺服器(區網可用手機連線測試)
npm run build    # 型別檢查 + 打包到 dist/
```

## 操作

| 裝置 | 移動 | 放爪 |
|---|---|---|
| 桌機 | 方向鍵 / WASD,或拖曳畫面搖桿 | 空白鍵 / 「放爪」鈕 |
| 手機 | 左下虛擬搖桿 | 右下「放爪」鈕 |

右上角:🎥 切換視角(正面 / 側面 / 俯視)、🛒 進貨與上架、⚙️ 營運設定(售價、爪力、今日數據)、🔊 音效。
營業中由顧客自己操作機台;準備階段可「試玩」(免費,贏到的娃娃會放回倉庫)。

## 經營玩法(P2)

一天分四段:**準備**(試玩、進貨、上架、調整售價與爪力)→ **營業**(10:00~22:00,可加速 1×/2×/4×)→ **打烊** → **結算報告**。

- 顧客有 4 種類型(學生、情侶、老手、小朋友),預算、技術、耐心、價格敏感度各不相同,會自己排隊、操作爪子玩。
- 夾到了心情變好,夾不到心情變差,心情低於門檻就生氣離開;排太久也會走。
- 每天的平均滿意度影響**聲望**,聲望影響客流。
- 售價:太低客人擠爆但賺得少,太高客人變少。
- 爪力:太強常中獎、獎品成本吃掉利潤,太弱客人生氣離開。
- 存檔在瀏覽器 localStorage,設定面板可重新開始。

## 架構

```
src/
├─ config.ts       常數:機台尺寸、爪子速度、稀有度
├─ economy.ts      經濟:進貨包、成本、房租、存檔、結算
├─ game.ts         遊戲主控:營業日階段、事件、統計
├─ customers.ts    顧客 AI、排隊、電腦操作爪子
├─ human.ts        程序化人物模型與動作
├─ ui.ts           介面(HUD、進貨、報告)
├─ physics.ts      Rapier 剛體世界:地板/出口/玻璃、娃娃生成、得獎偵測
├─ claw.ts         爪子:物理剛體 + 狀態機 + 爪力模型
├─ plush.ts        程序化毛絨娃娃模型與材質(6 種 × 3 稀有度)
├─ cabinet.ts      機台 3D 模型:外殼、玻璃、龍門架、操作台、LED
├─ environment.ts  店內場景:地板、牆面、霓虹、鄰近機台
├─ render.ts       渲染管線(PBR、Bloom、MSAA)與鏡頭
├─ input.ts        鍵盤 + 虛擬搖桿
├─ audio.ts        WebAudio 合成音效
├─ textures.ts     全部貼圖以 canvas 程序生成(無外部素材)
└─ main.ts         遊戲主迴圈、UI 綁定
```

分三層,方便之後接經營系統:**模擬層**(physics / claw)、**表現層**(cabinet / plush / render)、**介面層**(index.html / input)。

### 爪子狀態機

`idle → play → descend → close → lift → travel → release → return → idle`

### 爪力模型(經營系統的核心旋鈕)

真實的娃娃機靠「爪力時強時弱」控制出貨率。這裡用兩段式:

1. 夾取當下由真實物理決定能不能包住娃娃(爪子是運動學剛體)。
2. 起吊時依 `strength` 換算保持機率(`strength^1.4 × 0.75`)擲骰:失敗則在 0.2~1.8 秒內完全鬆爪,成功則以彈簧阻尼輔助提起。

`strength`(0.15~0.95)由「營運設定」調整。實測成功率約:30% 爪力 25%、50% 爪力 38%、80% 爪力 60%。
