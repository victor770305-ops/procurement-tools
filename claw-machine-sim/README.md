# 夾娃娃樂園 Claw Club(原型 P0 ~ P2+)

網頁版 3D 夾娃娃機經營模擬遊戲。目前完成「整間店的營運模擬」:3 台機台、收銀櫃台、倉庫貨架、3 位員工、顧客 AI、營業日、進貨補貨、售價與爪力取捨、每日結算與聲望。桌機與手機皆可操作。

## 執行

```bash
cd claw-machine-sim
npm install
npm run dev      # 開發伺服器(區網可用手機連線測試)
npm run build    # 型別檢查 + 打包到 dist/
```

## 操作

| 裝置 | 移動 | 放爪 |
|---|---|---|
| 桌機 | 方向鍵 / WASD,或拖曳畫面搖桿 | 空白鍵 / 「放爪」鈕 |
| 手機 | 左下虛擬搖桿 | 右下「放爪」鈕 |

右上角:🎥 切換視角(正面 / 側面 / 俯視)、🛒 進貨與上架、⚙️ 營運設定(售價、爪力、今日數據)、🔊 音效。
營業中由顧客自己操作機台;準備階段可「試玩」(免費,贏到的娃娃會放回倉庫)。

## 整間店怎麼運作

**店面:** 3 台機台排成一列,右側是換幣櫃台與入口,左側是倉庫貨架。預設是「全店視角」,🎥 可切換為近看或俯視選取的機台,📊 開啟營運總覽。

**一天的流程:** 準備(試玩、進貨、請店員補貨、調整售價與爪力)→ 營業(10:00~22:00,可 1×/2×/4× 加速)→ 打烊 → 結算報告。

**客人動線:** 入口 → 櫃台排隊換幣(收入在這裡入帳)→ 挑機台排隊 → 遊玩 → 幣用完離開,或心情好時回櫃台加買。幣沒用完就離開會退錢。
- 4 種客人(學生、情侶、老手、小朋友),預算、技術、耐心、價格敏感度各不相同。
- 夾到了心情變好,夾不到變差;連輸會舉手請店員協助;心情太差或等太久就離開。

**員工(3 人,每人日薪 NT$90):**
- 小美(收銀):在櫃台為客人換幣、打招呼。
- 阿凱、小雯(理貨):自動判斷工作,優先順序為協助客人 → 補貨 → 清潔,沒事就巡場。
  - 補貨:去倉庫貨架拿貨 → 搬到機台 → 等爪子空檔 → 機台暫停服務 → 補進娃娃。
  - 協助:客人連輸時,把最靠近出口的娃娃推一把,客人心情回升。
  - 清潔:擦玻璃,維持店面清潔度(影響客人進門時的心情)。

**營運總覽(📊):** 每台機台的狀態、庫存、排隊、今日遊玩與中獎;員工目前在做什麼;即時活動紀錄。

**經濟:**
- 售價:太低客人擠爆但賺得少,太高客人變少。
- 爪力:太強常中獎、獎品成本吃掉利潤,太弱客人生氣離開。
- 固定支出:房租 NT$200 + 員工薪資 NT$270,每天 NT$470。
- 每天平均滿意度影響聲望,聲望影響客流。
- 存檔在瀏覽器 localStorage。

## 架構

```
src/
├─ config.ts       常數:機台尺寸、爪子速度、稀有度
├─ economy.ts      經濟:進貨包、成本、房租、存檔、結算
├─ game.ts         遊戲主控:營業日階段、事件、統計、活動紀錄
├─ machine.ts      單台機台:外觀 + 獨立物理世界 + 爪子 + 排隊 + AI 駕駛員
├─ staff.ts        員工:收銀、補貨、清潔、協助客人的任務狀態機
├─ layout.ts       店面佈局座標與機台主題
├─ customers.ts    顧客:櫃台換幣、選機台、排隊、遊玩、離開
├─ human.ts        程序化人物模型與動作
├─ ui.ts           介面(HUD、進貨、報告)
├─ physics.ts      Rapier 剛體世界:地板/出口/玻璃、娃娃生成、得獎偵測
├─ claw.ts         爪子:物理剛體 + 狀態機 + 爪力模型
├─ plush.ts        程序化毛絨娃娃模型與材質(6 種 × 3 稀有度)
├─ cabinet.ts      機台 3D 模型:外殼、玻璃、龍門架、操作台、LED
├─ environment.ts  店內場景:地板、牆面、霓虹、鄰近機台
├─ render.ts       渲染管線(PBR、Bloom、MSAA)與鏡頭
├─ input.ts        鍵盤 + 虛擬搖桿
├─ audio.ts        WebAudio 合成音效
├─ textures.ts     全部貼圖以 canvas 程序生成(無外部素材)
└─ main.ts         遊戲主迴圈、UI 綁定
```

分三層,方便之後接經營系統:**模擬層**(physics / claw)、**表現層**(cabinet / plush / render)、**介面層**(index.html / input)。

### 爪子狀態機

`idle → play → descend → close → lift → travel → release → return → idle`

### 爪力模型(經營系統的核心旋鈕)

真實的娃娃機靠「爪力時強時弱」控制出貨率。這裡用兩段式:

1. 夾取當下由真實物理決定能不能包住娃娃(爪子是運動學剛體)。
2. 起吊時依 `strength` 換算保持機率(`strength^1.4 × 0.75`)擲骰:失敗則在 0.2~1.8 秒內完全鬆爪,成功則以彈簧阻尼輔助提起。

`strength`(0.15~0.95)由「營運設定」調整。實測成功率約:30% 爪力 25%、50% 爪力 38%、80% 爪力 60%。
