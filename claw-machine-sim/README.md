# 夾娃娃樂園 Claw Club

網頁版 3D 夾娃娃店經營模擬。你是店長:60 台台灣標準機型的娃娃機、2 台兌幣機、輪班店員、有名有姓的顧客與常客、隨機事件與日常營運劇情,用上帝視角觀察整間店。桌機與手機皆可操作。

## 執行

```bash
cd claw-machine-sim
npm install
npm run dev      # 開發伺服器(區網可用手機連線測試)
npm run build    # 型別檢查 + 打包到 dist/
```

## 整間店怎麼運作

**機台:** 參考台灣常見的標準機型。方正直立的黃色(依主題變色)外框、上半是玻璃櫃、下半是印滿卡通圖案的櫃身、側邊突出投幣箱(投幣孔、搖桿、抓取按鈕、顯示幕)、底下有輪子、頂部是招牌與氣球。共 8 種主題(TOY TOWN、FUN LAND、HAPPY ZOO、SWEET POP…)。

**店面:** 6 排 × 10 台機台,排與排之間是走道;前廳有 2 台兌幣機、倉庫貨架與員工休息室入口。

**一天的流程:** 準備(試玩、進貨、請店員補貨、設定班表與售價)→ 營業(10:00~22:00,可 1×/2×/4×/8× 加速)→ 打烊 → 結算報告。

**客人動線:** 大門 → 兌幣機排隊換幣 → 挑機台排隊 → 遊玩 → 幣用完離開,或心情好時回兌幣機加買。沒用完的幣在離開時退錢。
- 4 種客人(學生、情侶、老手、小朋友),預算、技術、耐心、價格敏感度各不相同。
- 夾到了心情變好,夾不到變差;連輸會舉手請店員協助;心情太差或等太久就離開。
- 客人與店員只走走道與側通道,不會穿過機台。

**店員(早班、晚班各 3 或 4 人,每人每班 NT$400):** 全部自動判斷工作,依緊急程度和距離從「任務看板」挑事做:
- 補貨:去倉庫貨架拿貨(一次最多 24 隻)→ 搬到機台 → 等這一局結束 → 補進娃娃。
- 協助客人:連輸的客人請求協助時,把最靠近出口的娃娃推一把。
- 維修機台、取出卡在洞口的獎品、清理地上水漬、擦玻璃、為兌幣機補零錢或排除卡鈔。
- 沒事就巡場、跟客人打招呼。早晚班在 16:00 換班,下班的店員走回休息室。

**隨機事件(營業中):**
| 事件 | 後果 | 解法 |
|---|---|---|
| 機台故障 | 停機,排隊客人改去別台,目前這局退幣 | 店員維修(約 9 秒) |
| 獎品卡洞 | 客人等著拿獎品,機台暫停 | 店員取出,客人才算贏得 |
| 客人打翻飲料 | 地上有水漬,經過的客人可能滑倒,影響滿意度 | 店員拖地,現場放黃色告示牌 |
| 兌幣機卡鈔 / 缺零錢 | 換不到幣,排隊的人改去另一台 | 店員排除或補零錢 |

**人物系統:** 老闆、8 位店員、8 位常客、以及每位隨機顧客都有獨立的人物設定:姓名、職位、簡介、個性標籤、外觀(臉型、髮型、眼鏡、制服…)與**六項能力**。點任何人會開啟人物卡:插畫風肖像(依心情或士氣換表情)、六邊形能力圖、即時狀態,還能「追蹤」讓鏡頭跟著他走。
- 店員六項能力:速度、細心、技術、親和、體力、抗壓。**真的會影響遊戲**:速度決定走路快慢,各種工作的耗時看對應的能力(補貨看速度與體力、維修看技術、協助客人看親和、拖地與取獎品看細心),士氣低會變慢。
- 顧客六項能力:技術、預算、耐心、運氣、收藏慾、社交,分別影響瞄準精度、換幣數量、排隊耐心、成功率、挑稀有款的傾向。
- 老闆的六邊形由實際經營數據算出:營收力、口碑、現金流、人事、設備、庫存。
- 常客(阿嬤、小傑、阿明…)會反覆出現,記錄來店次數,也會出現在劇情裡。

**日常營運劇情:** 每天早上有一張「晨會案例」,營業中還可能跳出「臨時狀況」(中午、傍晚各一次)。每張卡有出場角色、情境和 2~3 個選項,選項有明確的代價與後果:現金、聲望、員工士氣、請假、能力成長,或是持續幾天的店況加成(客流、水漬、故障、卡鈔機率、爪力、租金)。部分選項是機率分支,有些會在幾天後引出後續(例如拒絕加薪的阿凱會遞辭呈)。所有決定都記錄在 📖 營運日誌。劇情卡跳出時模擬會暫停。

**營運總覽(📊):** 機台狀態統計、選取機台的詳情、待處理事項與負責的店員、在班店員正在做什麼、兌幣機狀態、即時活動紀錄。

**經濟:**
- 售價:太低客人擠爆但賺得少,太高客人變少。實測最佳區間約 20~25 元。
- 爪力:太強常中獎、獎品成本吃掉利潤,太弱客人生氣離開。
- 固定支出:房租 NT$2,500 + 店員薪資(早晚班人數 × NT$400)。
- 兌幣機只有兩台,是整間店的瓶頸;前廳排太長客人會直接走掉。
- 每天平均滿意度影響聲望,聲望影響客流。
- 存檔在瀏覽器 localStorage。

## 架構

60 台機台的關鍵是**雙層細節(LOD)**:只有你近看的機台(以及視角拉近時附近的 3 台)是完整版,有真實物理、爪子與娃娃;其餘機台是實例化的簡化模型,遊玩結果由機率模型決定(成功率沿用完整版實測的曲線),庫存清單在兩層之間完整保留。

```
src/
├─ main.ts         啟動、介面事件、主迴圈
├─ game.ts         遊戲主控:營業日、輪班、事件、細節層切換、結算、營運總覽資料
├─ layout.ts       店面座標、走道路徑規劃(route)、機台主題
├─ machine.ts      一台機台:近看層(物理+爪子)/ 遠景層(機率模型)、故障、卡洞、AI 駕駛員
├─ lite.ts         遠景層:60 台機台以實例化網格一次畫完
├─ characters.ts   人物設定:老闆、店員、常客、隨機顧客(姓名、職位、簡介、外觀、六項能力)
├─ portrait.ts     以程式繪製插畫風人物肖像(依外觀與表情)
├─ boss.ts         老闆 NPC
├─ stories.ts      日常營運劇情庫(20 張卡、機率分支、連鎖後續)
├─ customers.ts    顧客:兌幣機換幣、選機台、排隊、遊玩、離開、滑倒
├─ staff.ts        店員:輪班、任務看板、補貨/維修/協助/拖地等任務狀態機
├─ events.ts       隨機事件導演與水漬
├─ exchange.ts     兌幣機(卡鈔、缺零錢)
├─ economy.ts      成本、薪資、進貨包、存檔、結算
├─ physics.ts      Rapier 剛體世界(每台近看機台一個)
├─ claw.ts         爪子:物理剛體 + 狀態機 + 爪力模型
├─ plush.ts        程序化毛絨娃娃(6 種 × 3 稀有度,同款共用幾何)
├─ cabinet.ts      近看層機台 3D 模型(台灣標準機型,夾物區縮放後放進外殼)
├─ human.ts        程序化人物(完整版 / 遠景簡化版)
├─ environment.ts  大廳:地毯與磁磚走道、牆面、前廳、倉庫、照明
├─ render.ts       渲染管線與鏡頭(上帝視角平移縮放、近看)
├─ ui.ts           介面
└─ audio.ts / input.ts / textures.ts / config.ts
```

### 爪力模型

真實的娃娃機靠「爪力時強時弱」控制出貨率:
1. 夾取當下由真實物理決定能不能包住娃娃(近看層)。
2. 起吊時依 `strength^1.4 × 0.75` 擲骰決定保持還是中途鬆爪。
3. 遠景層直接用 `0.75 × strength^0.9 × (0.8 + 0.4 × 客人技術)` 當成功率。

## 已知限制
- 遠景層的機台不跑物理,所以拉遠時看不到爪子在動,只有狀態燈與娃娃堆。
- 3D 人物是程序化的低多邊形模型,比例自然但不是精緻角色;人物肖像是程式繪製的插畫,不是 3D 渲染。
- 效能在桌機上順暢;手機請從遠景視角使用,避免同時近看太多機台。
